# Security policy

This maintained fork preserves the security model and MIT licensing of the upstream [ModernBIOSManagement](https://github.com/MSEndpointMgr/ModernBIOSManagement) project.

Please report suspected vulnerabilities privately through GitHub's **Report a vulnerability** feature for this repository. Do not include passwords, BIOS credentials, or other sensitive deployment data in public issues or pull requests.

Security fixes should preserve upstream attribution and the parent-project relationship. Changes that affect runtime flashing behavior require focused review and testing on supported hardware.
